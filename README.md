# MVP Monitoring of Public Procurement 🇰🇿

A data-driven compliance and anomaly detection tool designed to analyze public procurement contracts, map supplier-customer networks, and highlight unusual patterns (such as frequent pairings or high-volume single-source contracts).

## Features
- **Data Processing:** Clean and analyze large-scale procurement datasets using `Pandas`.
- **Graph Networks:** Build and analyze relationship networks between state customers and suppliers using `NetworkX`.
- **Anomaly Detection:** Automatically flag high-risk patterns like frequent direct-source contracts and key market hubs.
- **Interactive UI:** (Coming soon) Web dashboard built with `Streamlit`.

## Tech Stack
- **Python** (Core logic)
- **Pandas** (Data manipulation)
- **NetworkX** (Graph theory & network analysis)
- **Streamlit** (Web interface)

## Status
MVP (Minimum Viable Product) developed as a first-year university project in Information Science & AI/ML.
